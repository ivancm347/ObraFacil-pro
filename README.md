# ObraFácil PRO v2.2

Gestão de orçamentos, produtos, clientes e obras - PWA com React + Vite.

## Rodar local
npm install
npm run dev

## Deploy GitHub Pages
1. Push para branch main
2. GitHub Actions faz build automaticamente (ver .github/workflows/deploy.yml)
3. Site em https://ivancm347.github.io/ObraFacil-pro/

Stack: React 18, Vite 5, vite-plugin-pwa, jspdf, localStorage
